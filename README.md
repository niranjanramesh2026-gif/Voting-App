# Voting-App
# 🗳️ Desktop Voting Machine Application

This is a desktop voting application I built entirely on my own using Python. It lets you register two custom party names, take live votes on a separate screen, and automatically calculates the results to declare a winner!

## ✨ Features I Built
* **Multi-Window Navigation**: The app opens an entry screen, transitions to a voting panel, and displays a final results layout.
* **Keyboard Navigation**: Includes custom keyboard shortcuts (`<Tab>` and `<Return>`) to help move through inputs easily.
* **Dynamic Margins**: Tracks score counts and calculates the exact winning vote margin using mathematical absolute values.
* **Sleek UI Design**: Mixed standard interface labels with CustomTkinter elements to give the submit button smooth, rounded edges.

## 🛠️ Tools Used
* **Python** (Core coding language)
* **Tkinter & CustomTkinter** (Window framing, labels, layout coordinates, and buttons)
## ⚙️ Installation Prerequisites

Before running this application, you must install the CustomTkinter library [source: 1]. Open your command prompt or terminal and run the following command:

```bash
pip install customtkinter
```
